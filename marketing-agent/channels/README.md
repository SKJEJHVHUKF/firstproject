# פלייבוק לפי ערוץ

הסוכן משתמש בקבצים כאן רק לערוצים שסומנו ✅ בפרופיל.
כל ערוץ: תפקיד בחדירה, תדירות, פורמט מנצח, ומדד.

| ערוץ | תפקיד טיפוסי | תדירות ל-14 יום | פורמט מנצח למטאוורס | מדד |
|---|---|---|---|---|
| **אינסטגרם** | ראשי (B2C) | ריל יומי + 3–5 סטוריז | ריל "תגובה ראשונה" / סיור POV | הגעה, שמירות, DM |
| **טיקטוק** | ראשי (קהל צעיר) | 1–2 סרטונים ביום | POV, לפני/אחרי, "ניסוי" | צפיות, שיתופים |
| **פייסבוק דף** | תמיכה | פוסט יומי | קרוסלה + סרטון | הגעה, תגובות |
| **קבוצות פייסבוק** | חשיפה מהירה | 3–5 קבוצות ביום, ערך קודם | פוסט ערך + הזמנה לדמו | הודעות נכנסות |
| **וואטסאפ** | המרה | רשימת תפוצה: 3 הודעות ב-14 יום. קבוצות: 1 ב-3 ימים | הודעה קצרה + סרטון 20 שנ' | תגובות, סגירות |
| **טלגרם** | קהילה | יומי | עדכונים + מאחורי הקלעים | הצטרפויות |
| **לינקדאין** | ראשי (B2B) | פוסט יומי מהפרופיל האישי + 10 פניות DM ביום | סיפור + מספרים, מקרה בוחן | תגובות, פגישות |
| **יוטיוב** | עומק / SEO | 2 סרטונים + שורטס יומי | דמו מלא 3–5 דק', שורטס מהריל | צפייה, מנויים |
| **דיסקורד** | קהילת מטאוורס | יומי | אירועים חיים בתוך החוויה | חברים פעילים |
| **מייל** | המרה | 3 מיילים: השקה / סיפור / סגירה | מייל אישי קצר | פתיחה, קליקים |
| **ממומן** | מאיץ | ימים 3–14, 2 שלבים: רחב → ריטרגטינג | סרטון הדמו, מטרה = הודעות | עלות להודעה / לליד |
| **משפיענים** | הוכחה חברתית | 5–10 פניות, 2–3 שיתופים | התנסות + תגובה אותנטית | הגעה, לידים מקוד |
| **אירועים / הדגמות** | סגירה | 1–2 הדגמות קבוצתיות | הדגמה חיה 30 דק' + הצעה בסוף | המרה במקום |

## כלל בחירת ערוצים
- **B2C צעיר** → טיקטוק ראשי, אינסטגרם תמיכה, וואטסאפ/DM המרה.
- **B2C 30+** → אינסטגרם ראשי, קבוצות פייסבוק תמיכה, וואטסאפ המרה.
- **B2B** → לינקדאין ראשי, מייל/וואטסאפ תמיכה, הדגמה חיה המרה.
- **קהילת גיימינג/מטאוורס** → דיסקורד/טיקטוק ראשי, יוטיוב תמיכה, דיסקורד המרה.
