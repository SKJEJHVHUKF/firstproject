# תבניות תוכן לפי פורמט

## ריל / טיקטוק (15–45 שניות)
```
[0–3 שנ'] Hook ויזואלי: הרגע הכי "וואו" מהחוויה + טקסט על המסך
[3–15 שנ'] הבעיה בשני משפטים (קול / כתוביות)
[15–35 שנ'] הפתרון – להראות, לא להסביר. סיור מהיר.
[35–45 שנ'] CTA + הצעת ההשקה
כיתוב: Hook + 2 שורות + CTA + 5–8 האשטגים
```

## פוסט אינסטגרם / פייסבוק (קרוסלה)
```
שקף 1: Hook גדול (עד 8 מילים)
שקף 2–3: הכאב
שקף 4–6: הפתרון בתמונות אמיתיות מהחוויה
שקף 7: הוכחה (המלצה / מספר)
שקף 8: CTA
```

## פוסט לינקדאין (B2B)
```
שורה 1: Hook מקצועי (טענה או מספר)
[רווח]
3–5 שורות: הסיפור / הלקח / המקרה
[רווח]
3 נקודות: מה זה אומר לעסק שלכם
[רווח]
שאלה לדיון + CTA עדין ("מי רוצה לראות דמו? בתגובות")
```

## סטורי (סדרה של 3–5)
```
1: שאלה / סקר ("ניסיתם פעם מטאוורס?")
2: תשובה + קטע מהחוויה
3: המלצה / סקרינשוט
4: CTA עם סטיקר לינק / "שלחו הודעה"
```

## הודעת וואטסאפ לקבוצה (ערך קודם!)
```
היי [שם הקבוצה] 👋
[משפט ערך – טיפ / תובנה שקשורה לקבוצה]
בנינו [מה] שעוזר ל-[קהל] ל-[תוצאה].
פותחים [X] מקומות להתנסות חינמית השבוע.
מי שרלוונטי – שיכתוב לי בפרטי 🙏
```

## הודעת DM / וואטסאפ אישית (אאוטריץ')
```
היי [שם], [משפט אישי – למה דווקא אליו/ה].
אנחנו משיקים את מטאפ – [משפט אחד מה זה].
חשבתי שזה יכול להתאים ל-[ההקשר שלו/ה].
אשמח להראות לך ב-10 דקות, בלי התחייבות. מתי נוח?
```

## מייל השקה
```
נושא: [Hook קצר, עד 6 מילים]
פתיחה: משפט אחד אישי.
הבעיה: 2 משפטים.
הפתרון: 3 משפטים + לינק לסרטון.
ההצעה: מה, עד מתי, כמה מקומות.
CTA: כפתור/לינק אחד.
חתימה אישית.
```

## פנייה למשפיען / שותף
```
היי [שם], עוקב/ת אחרי התוכן שלך על [נושא] – [מחמאה ספציפית].
אנחנו מטאפ, [משפט אחד]. חשבתי שהקהל שלך ייהנה מזה.
מציע/ה: גישה חינמית מלאה + [תמורה: עמלה / תשלום / חשיפה].
רק לנסות ולהגיד מה חשבת. מתאים?
```
