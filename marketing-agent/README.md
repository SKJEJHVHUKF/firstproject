# סוכן השיווק – מטאפ (Metaverse) 🚀

תשתית לסוכן שיווק שרץ בתוך Claude Code ומנהל חדירה חזקה לשוק תוך 14 יום.

## איך זה עובד

1. **ממלאים את `business-profile.md`** – מי אתם, מה מוכרים, למי, ובאילו ערוצים אתם נמצאים.
   זה הקובץ היחיד שחובה למלא. כל השאר נגזר ממנו.
2. **מריצים `/marketing`** ב-Claude Code בתוך הריפו.
   הסוכן קורא את הפרופיל, בונה את תוכנית 14 הימים בהתאמה לערוצים שלכם, וכותב את התוכן ליום הראשון.
3. **כל יום מריצים `/marketing היום`** – הסוכן מוציא את חבילת התוכן היומית לכל ערוץ,
   מעדכן את יומן המעקב ומתאים את התוכנית לפי מה שעבד אתמול.

## פקודות

| פקודה | מה קורה |
|---|---|
| `/marketing` | אבחון + בניית התוכנית המלאה ל-14 יום |
| `/marketing היום` | חבילת תוכן יומית לכל הערוצים (פוסטים, סטוריז, הודעות, מיילים) |
| `/marketing ערוץ אינסטגרם` | תוכנית עומק ו-14 פוסטים לערוץ אחד |
| `/marketing סיכום שבועי` | ניתוח ביצועים, מה לחזק ומה לזרוק |
| `/marketing מתחרים` | מיפוי מתחרים ומה אפשר לקחת מהם |

## מבנה התיקייה

```
marketing-agent/
├── business-profile.md       ← למלא! הפרופיל של העסק והערוצים
├── playbook-14-days.md       ← תוכנית החדירה ל-14 יום (שלד שהסוכן מתאים)
├── channels/                 ← פלייבוק לכל ערוץ אפשרי
├── templates/                ← תבניות תוכן מוכנות (hooks, פוסטים, הודעות, מיילים)
├── tracking.md               ← KPI ויומן יומי
└── output/                   ← הסוכן כותב לכאן את התוכן היומי (נוצר אוטומטית)
.claude/
├── skills/marketing/SKILL.md ← ההוראות של הסוכן (הפקודה /marketing)
└── agents/marketing-agent.md ← הגדרת סוכן-משנה לעבודה ברקע
```

## עקרון מנחה

חדירה לשוק בשבועיים לא נעשית ע"י "קצת מכל ערוץ". היא נעשית ע"י:
- **ערוץ ראשי אחד** שמקבל 60% מהמאמץ (איפה שהקהל שלכם כבר נמצא).
- **ערוץ תמיכה אחד** (30%) שמחזק ומפנה לערוץ הראשי.
- **ערוץ המרה אחד** (10%) – וואטסאפ / דף נחיתה / DM – איפה שסוגרים.

הסוכן בוחר את השלושה לפי הפרופיל שלכם ומסביר למה.
